# Lyric document contract

Bounded scope: owned timed Unicode text, separate physical/logical clocks, delivery setting, group/nth track, CRUD, clipboard and whole-document history. Timeline bulk selection/drag, meter reanchoring, negative pickup positions, tool notification/Message Window delivery and playback behavior remain acceptance work. This contract does not establish full LyricStripMgr compatibility.

Primary sources: local `work/analysis/sources/dmusicf.h` (DMUS_IO_LYRICSTRACK_EVENT_HEADER and Lyric hierarchy), `dmusici.h` (DMUS_PMSGF_TOOL constants), and extracted Producer help `work/analysis/help/htm/lyricproperties.htm`. Dynamic original observations and immutable inputs are in `work/analysis/q3-lyric/20261004T212600Z`.

Original GUI created a Lyric track in the previously source-authored Segment accepted by original Producer (tempo and three Marker events retained). These are original-authored Lyric observations, not a claim that the entire Segment originated in original Producer. Save As exports a copy without changing the active SourceMarkers.sgp path; preserved prior evidence is not overwritten.

Original empty Lyric track has trkh/trkx and **no lyrt payload**. GUID is 995c1cf5-54ff-11d3-8bda-00600893b1b6; group 1; trkh list type lyrt; trkx flags 16. Adding an event creates LIST lyrt / LIST lyrl / LIST lyre, containing lyrh and lyrn. Empty payload omission is valid and no-edit load/save must retain it exactly.

lyrh is at least 16 bytes: reserved DWORD flags at 0 (zero), delivery DWORD at 4, logical MUSIC_TIME at 8, physical MUSIC_TIME at 12. SDK documents combinations of immediate=4, queue=8 and at-time=16, excluding clock-domain/flush/lock flags. Original default UI selects At Time Stamp; Quick response saved 4 and Before Time Stamp saved 8. `OriginalUnicodeQuick.sgp` stores both clocks 3072. `OriginalSeparatedBefore.sgp` stores physical 3085 (bar 2, beat 1, tick 13), logical 6144 (Belongs To bar 3, beat 1), delivery 8. Do not derive logical time from physical time during edits or paste.

lyrn contains null-terminated UTF-16LE. Original `歌詞 Ω first` stores 20 text bytes, a two-byte terminator and six trailing zero bytes. Preserve bytes after the first terminator, header extensions, unrecognized chunks, sibling order and RIFF padding when editing. Reject unpaired surrogate or embedded NUL input. The original timeline rendered garbled ANSI glyphs while properties and saved UTF-16 held the correct string; that display observation does not prove data corruption.

Mutations copy the whole document, validate selection/clock/Unicode/delivery/container ambiguity, then commit. Failures preserve bytes, dirty state, redo history and output selection. Current supported insertion clocks satisfy 0 <= physical/logical < Segment length. Negative pickup/meter behavior remains explicit compatibility work. Clipboard owns one complete lyre entry, including extensions, and accepts independent target clocks. SDK delivery combinations are retained; only 4 and 8 were dynamically saved so far. Equal-time/multiple-selection behavior is not yet an original oracle.

Native byte audits complement dynamic original observations. Final interoperability requires the same candidate GUI save/reload and original reciprocal edits, and actual tool notification timing requires its own playback comparison.

Shared source Timeline range now includes an explicit selected-group/nth Lyric track. Selection uses physical clocks in [begin,end); relocation/paste applies one signed delta to both clocks, retaining their independent relationship even when logical time lies outside the physical selection. Both resulting clocks must remain inside Segment bounds. Blank selected ranges preserve span without manufacturing a missing track; overwrite removes only physical events inside the destination interval. Duplicate physical times retain stable source order under merge. These source policies are bounded and are not an original dynamic bulk oracle. Complete entries retain delivery, text, header extensions, trailing bytes and unknown entry children. Existing source-only TRNG v1 adds optional selected lyrc content; original COM/OLE clipboard remains unverified. Multi-strip mutations validate privately and commit one Undo/Redo transaction.
