# 0001：C++20＋JUCE 9＋CMakeを採用する

状態：採用済み。決定日：2026-11-10、ユーザー指定。

## 判断

新しい製品はC++20、JUCE 9、CMakeを軸にし、macOSではCore Audio／Core MIDIを利用する。GUI、デバイス、音声処理の基盤にJUCEを使い、音楽モデルと編集規則はアプリ側で所有する。

既存C++の知見を活かし、小さなMIDIシーケンサーから発展させる。旧COM構成・32bit ABI・原版UIの完全再現を、新製品の設計制約にはしない。

## 適用範囲

基本案はJUCE単体の基盤。Tracktion Engine等は調査時の比較資料として残し、導入の必須工程にはしない。必要性が生じた場合は別の採用判断として記録する。

JUCEのcommit固定、公開・配布時のライセンス方式、依存物のnoticeは実際の導入時に扱う。この採用記録は、既存コードのライセンス変更や商用契約の締結を意味しない。

詳細な比較と出典は[技術スタック調査](../reference/macos-technology-strategy-2026-11-10.md)。実施計画書は後の工程で作成する。
